三句话立场

  1. 学习快慢由回路闭环决定，不由输入量决定。提问 → 查一手 → 拆解 → 搭骨架 → 动手验证 → 输出 → 缺口回流。
  2. 没有调查就没有发言权。先查一手源，再下判断；查不到就标注，不假装查到。
  3. 输出是检验，不是副产品。讲不出来、写不出来、用不上，就等于没学会。

三张清单

学习前

  • 把「想学 X」改写成一句开放式问题。
  • 先写下你现在的答案，再看外部观点。
  • 定下输出物与截止时间（讲给谁 / 写成什么 / 用在哪个决策上）。

学习中

  • 3–5 个来源并行，专攻它们互相矛盾的地方。
  • 每次阶段转换插一次自检：我现在可能犯什么错？漏了哪条约束？
  • 任何结论先标置信度再写（事实 / 推断 / 推测-待确认）。

学习后

  • 输出一次（讲 / 写 / 用），记录暴露出的缺口。
  • 把新知识写进笔记库：一篇原子笔记 + 更新 hub。
  • 安排下一次检索式复习——合上资料重建，而不是重读。

来源与诚实边界

  • 笔记从另一个本地知识库只读抽取后重新析出，不复制原文；环境相关的绝对路径不写入笔记。
  • 抽取时发现源库 3 处标题与内容错配（标题像学习方法，正文其实是硬件排障与文件命名规则），未采信。
  • 学习金字塔百分比、「7 年达到顶尖」、网速百万倍、部分成本比例等数字无一手支撑，已在对应笔记内逐条标注，本站不把它们当事实展示。
  • 每篇笔记都写了它失效的条件与诚实范围（例如记忆宫殿的效果置信度是「推断」，未经验证）。
