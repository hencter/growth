# 快速进入领域 · 填空表

> 用法：复制本表到你的工作笔记，**边填边做**，不要先读完协议再填。任何一格写不出来，就说明对应阶段没做完——回那一格，别往下走。
> 协议本体：[[rapid-domain-entry-protocol|Rapid Domain Entry Protocol]]

## 0. 契约（30 分钟 · 先填这格）

```text
领域切片（不要写大领域名）：
交付物（决策/原型/对话/考试/文章）：
给谁看/用（具名）：
死线 + 档位（T0 3h / T1 9.5h / T2 29.5h）：
止损条件（什么情况下我停）：
本轮明确不学（写下来才算不学）：
我的开放式问题（一句）：
```
✅ 闸门：能用**一句话**说清「交付物 + 读者」。说不清 → 停在这里。

## 1. 领域地图（2 小时 · 一页五格）

来源只取结构，不深读：

| 源类型 | 我用了哪个 | 拿到什么 |
|---|---|---|
| 研究生课纲 / 阅读清单 | | 结构与顺序 |
| 综述 / 手册章节 | | 地图、历史脉络、开放问题 |
| 标准教科书目录 | | 学科公认的切分 |
| 百科 / 参考条目 | | 稳定定义与词汇 |
| 从业者路线图 / 岗位描述 / 工具文档 | | 真正在用 vs 已淘汰 |

```text
对象     ：这个领域在推理「什么东西」？
核心问题 ：它存在的 5-7 个问题（按重要性排）
方法     ：标准流程 / 模型 / 形式化工具
工具     ：从业者实际在跑、在读、在建的东西
分歧     ：可信来源互相矛盾之处（先记，不急着解决）
边界     ：这个领域明确不覆盖什么
```
✅ 闸门：**不看笔记**能说出 5 个核心问题。只能照着念 → 这是抄的，不是模型。

## 3. 复现（2.5 小时 · 跑通一个最小完整案例）

```text
我要复现的经典结果：
它的来源（论文/教材页码/官方示例）：
事先声明的容差（±多少 / 什么算通过）：
我用的版本 / 数据范围 / 单位：
实际结果：
差异与原因（或「为何无法对齐」）：
如果失败两次，我查过：版本 / 单位 / 数据范围 / 隐含约定 ——
```
✅ 闸门：落在容差内，或能**精确解释**为何对不上。

## 5. 产出（1.5 小时 · 300-600 字）

结构：**类比 → 最小定义 → 具体演示**（见 [[sandwich-teaching-method|Sandwich Teaching Method]]）

```text
我的开放式问题（从 S0 抄）：
给谁读：
类比（用对方本行的概念）：
最小定义（2-3 句，输入→处理→输出）：
演示（一个具体例子 / 我复现的结果）：
不确定的地方（诚实标注）：
交付动作：□ 已发送 □ 已发布 □ 已讲给____听
```
✅ 闸门：**有具名的人读过或听过**。

---

## 6. 抗遗忘 + 去向（0.5 小时）

- 入库：□ 领域地图 □ 术语表 □ 复现结论（各写成一篇原子笔记）
- 检索复习排程：**第 3 天 / 第 10 天 / 第 30 天** —— 合上资料重建地图，再与原件对账
- 决定：□ 停（止损条件已满足，归档） □ 续（下一轮把档位从 T_ 提到 T_，靶子写清楚：____）
